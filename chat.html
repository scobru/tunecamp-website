Connect. Encrypt. Communicate.

TuneCamp Chat is a standalone progressive web application and reusable client library for the TuneCamp ecosystem. Connect to any server instance, chat in public lobbies, lock rooms with custom passphrases, and send end-to-end encrypted direct messages.

Launch TuneCamp Chat View on GitHub

Zero-Knowledge E2EE

Direct messages and encrypted rooms are signed and encrypted directly in the browser via Zen SEA. Server nodes relay encrypted payloads without ever seeing plaintext content or encryption keys.

Passphrase-Locked Rooms

Create topic-based public or private channels. Lock rooms with a shared passphrase to create isolated, encrypted enclaves for collaborative sessions, bands, and label teams.

IRC Slash & Moderation

Rich command support with auto-completion: /kick, /ban, /unban, /clear, and global Zen moderation commands for instance admins and room owners.

React Hook & Client SDK

Integrate real-time federated chat into any web application in minutes using the official @tunecamp/chat npm package.

npm install @tunecamp/chat

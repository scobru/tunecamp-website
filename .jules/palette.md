## 2024-05-24 - Zero-Result Empty States Need Clear Actions
**Learning:** Users can get stuck in a zero-result state when heavily filtering or searching. A static message ("No tracks match your search") leaves them stranded.
**Action:** Always include an actionable "Clear Filters" button in zero-result empty states to provide a clear recovery path, which programmatically resets all filter inputs and re-triggers the list render.

## 2024-10-24 - Actionable Empty States
**Learning:** Zero-result empty states for search and filtering should provide users with a clear recovery path, but this UX pattern is frequently duplicated across multiple frontend files (e.g., `index.html`, `player.html`, `samples.html`).
**Action:** Always ensure that when implementing recovery actions like "Clear Filters" for empty states, the changes are applied consistently across all relevant HTML files to avoid a fragmented user experience.

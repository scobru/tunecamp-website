The Tunecamp Ecosystem

Standalone tools that extend Tunecamp. Each lives in its own repo and can be used independently.

Desktop Apps

Native companion apps you install and run outside the browser.

Sidecamp

github.com/scobru/sidecamp

Desktop App

Desktop companion app for TuneCamp. Search and download music from Soulseek, torrents, and YouTube, manage your local library, and share your collection back to the network as a peer node.

Graphofone

github.com/scobru/sidecamp/apps/graphofone

Desktop App

Standalone live-performance app built on the same graph engine as Sidecamp. Import a music folder, arrange tracks as a graph, link them with beat-matched crossfade transitions, and perform — fully offline, no P2P, no server.

Web Apps · TuneCamp Lab

Browser-based tools. Both run standalone and can be embedded as sandboxed iFrame apps under /lab on any TuneCamp instance — see the Lab docs.

tunecamp-4-track-recorder

github.com/scobru/tunecamp-4-track-recorder

Web App · Lab-ready

A browser-based 4-track cassette recorder built with the Web Audio API and Svelte 5. Low-latency overdub recording, latency compensation, sample-accurate playback — all client-side, no server needed.

Zen SEA · Identity Portal

Decentralized cryptographic identity for TuneCamp. Connect your node accounts using Zen SEA keys to aggregate public releases, starred favorites, and playlists into a single unified profile.

Sidecamp

github.com/scobru/sidecamp

Windows macOS Linux Android CLI Daemon

Desktop companion app for TuneCamp. Search and download music from Soulseek, torrents, and YouTube, manage your local library, and share your collection back to the network as a peer node.

TuneCamp Chat

github.com/scobru/tunecamp-chat

PWA E2EE (Zen SEA) React / Hook

Lightweight, decentralized, end-to-end encrypted messaging web application and React hook. Connects to any TuneCamp instance with real-time global lobby, passphrase-locked encrypted rooms, and 1-on-1 private DMs.

4-Track Recorder

github.com/scobru/tunecamp-4-track-recorder

Web App · Lab-ready

A browser-based 4-track cassette recorder built with the Web Audio API and Svelte 5. Low-latency overdub recording, latency compensation, sample-accurate playback — all client-side, no server needed.

Audiofabric

github.com/scobru/tunecamp-audiofabric

Web App · Lab-ready

Interactive 3D WebGL music visualizer built with regl and Web Audio API. Real-time audio-reactive terrain, dynamic waveforms, and shader effects. Connects to any TuneCamp stream via Subsonic API.
